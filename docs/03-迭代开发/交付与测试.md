# MVP 实施计划与放行单

## H1、H2 通过后的平台试点包

一个剧种、一个成人班、3 段获授权的短唱段，每段先选 3–5 句。每段至少有示范、实唱词、署名、有效许可、教师复核边界与一句听辨提示。收不到合格素材时可用老师专门录制且获许可的原创短句做原型，不对外声称获得经典唱段授权。P0 交付 F01–F07；P1 F08–F12，P2 F13–F16，详细定义见[功能与验收](../01-产品定义与技术预研/功能与验收.md)。第一版暂缓模型转写、自动评分、视频入库、自动推荐、同句双版本、公开问答及付费。完整练习路径为教师供稿 → 校订与审核 → 发班级链接 → 学员听前导、录一句、回听 → 标待练 → 再访接续。

## Sprint 按用户结果切分

T1–T2 属于阶段一。下表 T3–T7 是依赖工作项；周次仅供估工。通过需求验证与阶段二联合评审后，按以下闭环组合相关工作项，前后端在同一 Sprint 交付。

|Sprint|可独立演示的用户结果|共同验收|
|---|---|---|
|1 发出并听到第一份作业|老师提交授权示范和手填句表，审核员发给指定班级，学员打开链接听到目标句；审核员可撤回|抽取 T3–T6 的最小能力，走查 A01、A02、A05、A07 的对应路径|
|2 完成一次课后复练|学员听前导、本机录一句、交替回听、标记待练并从旧链接继续|联调 T5、T7，对照 A03、A04、A08；拒麦仍能练|
|3 老师独立更新作业|老师校订另一段、预览、送审并重发；已发布作业仍对应原修订|完善 T4、T6，走查 A05–A07 并回归前两个闭环|

## 工作项依赖与交接

以下周次是人员到位后的相对估算，假设有产品/研究、前后端、兼职测试、内容老师与独立审核人；资源缺口由项目负责人调整工期。AI 探索单独排期。

|任务 / 预计窗口|负责人与前置|具体产物与完成条件|
|---|---|---|
|T1 第1周 场景观察与授权|产品、内容；无|取得试点班意愿及许可范围，记录现行发视频练一句耗时；用纸面句卡验证入口|
|T2 第1周 内容样本与原型|教师、设计；首个授权样本|填一段完整词本、乐句、过门、入点；用同一段做移动听练与教师标注走查|
|T3 第2周 数据与身份|后端；T1–2、H1/H2 通过|落实班级访问、权利记录、修订与课项数据契约；构造重复/缺句/撤权夹具|
|T4 第2–3周 私有媒体|后端；T3|隔离上传、转码、范围取流、任务重试；用损坏音频及到期许可验证|
|T5 第3周 走通一条学习链|前端；T2–4|用真实授权样本在目标手机选句、听前导、循环、本地录音并交替回听|
|T6 第3–4周 制课与发布|前后端、老师；T3–4|桌面划句、署名、送审、退回/发布、撤回；老师独立完成剩余两段|
|T7 第4周 接续与可观测性|前后端；T5–6|本机及账号进度、去重/清除、最小事件统计、告警和故障回滚演练|
|T8 第5–6周 成人班试用|产品、测试；T1–7|完成下表测试后发试点；跟踪两周，报告使用分母、复练与退出原因，决定下一轮|
|T9 试点后 定向增强|算法与教师；T8 和研究授权|有需求先做手工双版本及句旁卡；另用封闭语料评估入点与拆解，逐项过门槛上线|

## 验收与回退

|编号 / 关联|操作条件|验收证据|
|---|---|---|
|A01 F01 F07|有效/过期班级链接、教师退回、发布后改稿、访问旧课|学员仅见可用课；旧练习保持快照；撤回后所有旧媒体请求拒绝|
|A02 F02|分别以 1×、0.75× 循环三次并切句，含无前导句|试听录屏与时间日志吻合老师边界，循环不串入下一句，老师听感认可|
|A03 F03|移动 Safari、安卓 Chrome、桌面浏览器各测授权、拒权、中断、无麦克风、删除|拒权仍可试听；结束后设备释放；网络捕获及存储检查无原声外传或持久化|
|A04 F04|掉线标待练，重连重复上报，登录接续并清除|单事件只计一次；删除后本机待传队列也清空，重登不复活|
|A05 F05|超限/损坏/伪装扩展名、超时、重复回调|隔离失败不发布；可换文件；任务恢复后同一输入一份派生结果|
|A06 F06|两人改同草稿；多次唱同词、夹过门、角色重叠|冲突通知可恢复；老师预览对应正确；越界拒绝且原草稿完好|
|A07 F07|跨班取流、老师自审、撤权时正在播放、备份恢复|服务端逐次校验，撤权恢复后仍生效，留下操作原因与时间|
|A08 全链|按 PRD 设定网络与屏宽测首播、大字、键盘，用户无需讲解完成试听到再练|提供耗时分布、录屏、缺陷清单；主流程阻断为零|

每次交付记录构建号、素材修订、测试设备、实际结果、复测人。上线负责人检查合规单及 P0 用例；高危权利/录音问题立刻暂停受影响服务、撤权并核查审计记录，播放故障回退上个兼容构建。P1 分功能开关，误报升高先关闭入点提示；保留手工练习。

**审查修订 · 试点包与 T1–T8。** 分为人工验证和平台试点。T1–T2 仅做一段三句，用获准的受控播放方式、手填句表和本机回听；人工执行审核、撤权及删除。无法控制受众时只做现场测试。H1、H2 通过后才排 T3–T8 和三段平台包。
