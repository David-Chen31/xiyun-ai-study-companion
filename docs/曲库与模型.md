# 曲库与模型

## 本机环境

模型版需要 Python 3.12、Node.js 24 和 FFmpeg。先在项目根目录安装 Python 依赖。

```powershell
py -3.12 -m pip install -r requirements.txt
```

| 本机路径 | 资源 |
| --- | --- |
| `.xiyun/llama-cpu/llama-server.exe` | [llama.cpp Windows CPU 发行包](https://github.com/ggml-org/llama.cpp/releases/tag/b12676) |
| `.xiyun/models/Qwen3-0.6B-Q4_0.gguf` | [Qwen3 量化权重](https://huggingface.co/ggml-org/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_0.gguf) |
| `.xiyun/models/crepe-tiny.onnx` | [CREPE Tiny ONNX](https://huggingface.co/Scicom-intl/crepe-onnx/resolve/main/crepe-tiny.onnx) |
| `.xiyun/models/UVR-MDX-NET-Voc_FT.onnx` | 可选人声分离模型。[UVR 模型](https://github.com/TRvlvr/model_repo/releases/download/all_public_uvr_models/UVR-MDX-NET-Voc_FT.onnx) |

`tools/start.ps1` 启动网页和仅绑定到本机的 LLM 服务。端口默认分别为 5173 和 5188，可通过 `-WebPort` 和 `-CoachPort` 修改。模型登录密钥由脚本生成在 `.xiyun/models/coach.key`。

## 添加曲目

1. 将原唱 MP3 放在 `library/audio/`。纯伴奏可另放，最好和原唱使用相同的起点、速度和删节。
2. 在 [曲库配置](../library/catalog.json) 添加唯一的英文曲目 ID、标题、歌手、时长和相对 `library/` 的 `source`。有独立伴奏时添加 `backing`。
3. 准备同一时间轴上的逐句 SRT。可以转录带时间的歌词，或用支持 Whisper 的 FFmpeg 生成初稿后听审。示范曲原始时间轴来自 Whisper Small，已有文本校正，逐句时间仍是初稿。
4. 生成评测与回听数据。命令以示范曲为例。已有等长干声时可直接使用该文件。或先运行人声分离。生成数据放在 `.xiyun/karaoke/<曲目ID>.json`。

```powershell
$origin = "library/audio/我不难过-孙燕姿.mp3"
$profile = ".xiyun/karaoke/wo-bu-nan-guo.json"
$vocals = ".xiyun/karaoke/reference-vocals.wav"
py -3.12 -X utf8 -m tools.extract_vocals $origin .xiyun/models/UVR-MDX-NET-Voc_FT.onnx $vocals
node tools/prepare_track.mjs wo-bu-nan-guo $origin .xiyun/karaoke/lyrics.srt $profile $vocals
py -3.12 -X utf8 -m server.pitch $profile $vocals --mix $origin
```

没有单独人声时，`prepare_track.mjs` 可省去最后一个参数以使用混音基础评测。已有核对过的逐字时间 JSON 时，可在参考人声参数后追加该文件。每个条目包含 `line_id`、`text`、`start_ms`、`end_ms`，可选 `pinyin`。重启服务载入曲库配置。

如果只有 MP3，FFmpeg 可使用本机 Whisper Small 模型 `ggml-small-q5_1.bin` 草拟逐句时间。以下命令假设已创建 `.xiyun/karaoke`。

```powershell
ffmpeg -i $origin -vn -af "whisper=model=.xiyun/models/ggml-small-q5_1.bin:language=zh:queue=28:destination=.xiyun/karaoke/lyrics.srt:format=srt:use_gpu=false" -f null NUL
```

[Whisper.cpp 模型文件](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small-q5_1.bin)
