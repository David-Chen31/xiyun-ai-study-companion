# 产品与验收

## 操作

| 页面 | 操作与反馈 |
| --- | --- |
| 曲库 | 从预制曲目进入练唱台。音频或参考数据缺失的曲目在列表标明状态。 |
| 练唱台 | 选择开始位置后录唱，或导入自己的录音。歌词随伴奏时间移动。录音结束后，受支持的句子显示局部音高分。 |
| 逐句点评 | 点歌词切到该句的评语。原唱和我的录音各有一个播放键和真实电平波形，竖线标记点评位置。可展开评分依据、表演与咬字练法，或重唱这句。 |

## 技术口径

`frontend/studio/` 处理界面和对听。浏览器将录音转换为 24 kHz 单声道 PCM 后交给回环地址上的 `/api/karaoke/pitch`，本机 CREPE Tiny 返回音高轨迹。模型无法给某句评分时可用自相关基线补充。原唱预先分离人声并生成同一模型的参考轨。逐句对齐限制在局部时间范围，覆盖不足时显示原因。

有测量证据时，`/api/karaoke/coach` 将唱词、音分、音名、持续时间和覆盖率交给本地 Qwen3，用于选择练法、解释情感处理并给出单独的 AI 练习分。练习分以声学结果为基础。发音指导是普通话示范，逐字诊断需要核对过的逐字时间。原声和模型请求留在设备，记录不持久化。

## 已验证的范围

- 《我不难过》有 65 个候选歌词区间。分离人声作为同源输入时，CREPE 独立覆盖 64 句，自相关补足其余一句。原混音单独作为同源对照时，41 句可比较。
- 将真实唱段整体升两个半音后，浏览器点评测到 +200 音分，并返回包含参考音名、延音时间和咬字示范的练法。440 Hz 测试音测得约 440.4 Hz。
- 桌面 Edge 走通过录音、导入、波形对听、点评和窄视口操作。不同演唱者、手机真机、逐字发音和混音串音的准确性仍待专项验证。
