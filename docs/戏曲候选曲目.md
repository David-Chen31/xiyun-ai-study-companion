## A 下一步如何启用

1. 为选段确定可用的录音来源、演唱者和允许的用途；先选一两首试用即可。建议黄梅戏单段和京剧拖腔段各一首，以便覆盖不同唱法；此为测试建议，并非教学难度评级。
2. 将对应原唱 MP3 放入 `library/audio/` 的登记位置；需要伴奏时另备同一时间轴的伴奏。音频留在本机忽略目录。
3. 更新 catalog 中的真实演唱者、实测时长和 recording_status；不能把参考网页中演唱者直接套给另一份录音。
4. 按 [曲库与模型](曲库与模型.md) 准备同一录音的 SRT，听审后运行现有曲目预处理和音高参考工具，输出到 `.xiyun/karaoke/<id>.json`。
5. 双人段落先按角色标注，戏曲拖腔和装饰音单独听审。没有证据时不以流行歌评分结果推断专业唱腔或咬字问题。
6. 重启服务，在页面验证选曲、歌词跟随、原唱/伴奏时间轴、导入录音和逐句点评。录音与参考数据齐备后才算可练习。
