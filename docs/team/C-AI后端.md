# C 的任务书｜AI 后端与音频计算

**你的交付对象是 A。** 给他一个独立运行的服务：发来教师示范和句表，你实测音频参数、检查每句时间，返回结果或指出错误字段。浏览器只和 A 通信。材料与算法输入由你协助校验，素材的授权和发布归 A。

## 每天的交付

|日|你先做什么|交给谁、怎样验|
|---|---|---|
|D1|在 ai_backend/ 建服务入口与独立测试。用生成的 12 秒 WAV 和一条时间记录跑通 inspect。|给 A 启动命令、端口配置、令牌配置和一条可重放的成功请求。A 从自己的进程调用并读出 12000 毫秒。|
|D2|读真实 WAV 头与帧，核对时长、声道、格式和每句界限。用老师复核的三句包与 A 联调。|交可运行服务、依赖锁、好样本及越界反例；越界时返回 422 和准确字段，空入点允许听练。|
|D3|核对请求编号、修订与算法版本；补齐非法令牌、坏音频、超限、重复句和临时文件清理。|把成功/失败结果交 A。停止 C 后已发课仍可练，新导入提示可重试；重启后再导入只发布一次。|
|D4|在第二个干净环境启动服务，比较预期与实测帧数/时长；记录耗时、样本来源和失败原因。|给 A 服务测试报告、安装问题和已知限制。请 B 试听第二句，区分人工标错与程序换算错。|
|D5|用最终交付版本复跑授权样本和坏包。|交启动说明、输入输出实例、测试结果、算法版本及回退版本；A 按说明能独立运行和验收。|

## 后续能力也由你接手

- **入点检测 F08、节奏音高 F13。** 设计校准、检测与弃判；设备端算法由你提供、B 集成。无声、蓝牙路由变化、低可信要回退自听。另行许可的离线研究集和实际字头金标用于盲测；自由录音默认只留本机。
- **拆解 F10、同步 F14、视频 F16。** 先有人工句界和锚点基线，再评估自动过门、唱词与局部对齐。跳句断开，两端修订变化即重审。视频保留音画偏移。输出是带版本的候选，A 管任务和采纳。
- **知识问答 F15。** A 限定有权材料，你实现检索、带引用生成和无证据拒答。各项进入排期前分别与 A 冻结任务输入、结果、失败示例。按[声学方案](../01-产品定义与技术预研/声学与知识方案.md)的覆盖、误报、基线比较及盲评条件申请放行。

## 自主权与检查

你决定分析库、算法内部实现和测试样本构造。你必须提交服务样例、评测步骤与结果。新增外部模型、改变音频传输目的、放宽弃判标准或修改请求格式，先与 A/B 共同确认。只改 ai_backend/、算法测试与技术样例，可分配给 C 的受控样本说明放 samples/；私有音频及授权原件按许可交接。提交 PR 附一条成功请求、一条失败请求及实测输出。[公共契约](API_CONTRACT.md) · [完整分工和合并规则](TEAM_PLAN.md)
