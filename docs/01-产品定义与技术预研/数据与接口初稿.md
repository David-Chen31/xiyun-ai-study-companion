# 用一份作业检验数据与接口边界

用一段三句的纸面样本走查下表。此时只需核对参与者、输入输出、失败时还能做什么。具体路由、索引、部署和供应商在阶段二决定。

|任务|对象与约束|请求与可观察结果|
|---|---|---|
|老师交示范、审核员发课|素材关联来源和授权；版本下的乐句使用原媒体毫秒。课项固定乐句修订与次序|老师提交句表和目标班级，独立审核人核准后返回班级链接。许可缺项退回草稿|
|学员回到指定句|作业快照含署名、前导、实唱词与句界；取流须同时满足课程与班级许可|打开链接得到有序句单，选句从本版本前导播放；撤课后停止新的取流|
|录后对听并复练|原声只在页面内存，待练位置引用快照与课项|录音和删除均在本机处理；再次打开已撤回作业显示下架原因|
|条件性入点研究|引导轨、录音与教师窗需要可信的时钟映射|校准失效只返回不可判断及复听动作；自由录音仅供自听|

用修改过句界的旧作业、过期许可、拒麦三例分别走查。若页面需要的事实没有来源，先修改任务或契约，再进入详细设计。
