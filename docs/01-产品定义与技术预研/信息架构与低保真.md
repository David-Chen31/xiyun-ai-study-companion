# 作业的信息架构与核心原型

学员从老师的作业链接进入，层级为班级作业 → 版本与句单 → 当前句。当前句承载试听、录音、交替回听与再练。首次定位老师首句，复访定位待练句。撤课原位说明；拒绝麦克风仍可循环听。

教师从有许可的示范进入，按素材 → 乐句草稿 → 作业预览 → 独立审核 → 班级链接组织信息。人工课包用句表模拟编辑区，审核人核对来源、署名与发布范围。先用[任务流程](任务流程.md)观察两端能否完成作业。
