# 功能基线与可检验行为

每行是一项可交付功能。优先级表示拟议发布批次；难度综合实现、数据和专业校验成本。P0 的手工内容链能独立运行。技术试验通过后才将对应 P1 功能交给学员。

|编号、优先级及理由|用户与问题|输入 → 操作 → 输出（主要交互）|依赖 / 难度|验收示例|
|---|---|---|---|---|
|F01 P0 课程入口，缩短首次寻找|学员找作业|班级作业链接 → 打开指定句单 → 展示授权课程、演员与署名|班级许可、目录索引 / 低|过期链接不能播放；仅一个剧种时直接列曲|
|F02 P0 逐句听练，核心学习动作|初学者找不到句首|参考音频、乐句 → 点唱词、前导、0.75×/1×、循环 → 听完整一句|人工边界、播放器 / 中|连播三轮止于同句末，换句取消旧循环；慢速后回原速位置连续|
|F03 P0 录后对听，提供自主反馈|学员想听自己唱|主动同意麦克风 → 录一句、停止 → 本机切换原唱/自己或删除|浏览器录音、设备检测 / 中|拒权可听练；切换时无双声；刷新后原声不可恢复，网络中无上传|
|F04 P0 学习进度，支持复练|学员下次接续|练习完成/手动收藏 → 保存记录与待练句 → 原链接继续|本机或账号事件去重 / 低|重复提交同一事件不重复计数；下架时提示换课|
|F05 P0 授权素材入库，内容前提|老师缺可用素材|许可凭据、音频、演绎信息 → 私密上传看进度 → 可试听草稿|隔离校验、转码、权限 / 中|格式不符拒绝；相同任务重试只产一份派生媒体|
|F06 P0 老师时间轴，保证边界可信|老师整理示范|草稿 → 拖边界或键入时间、填实唱词、角色、过门、入点及白话提示 → 校订版本|媒体时钟、修订控制 / 中|禁止负数和越界；同词重复可分开标；冲突提示重新合并|
|F07 P0 课程发布与撤回，形成闭环|老师布置、审核员把关|选句排序 → 预览学生视图 → 送审发布或退回 → 班级链接|许可、发布事务、撤权 / 中|许可失效禁止发布；已发布版本修改产生新草稿；撤回阻断旧链接|
|F08 P1 入点提示，有条件的增益|学员疑似抢入|校准、引导轨、录音 → 主动检测 → 早/晚/范围内或无法判断，回听再练|同钟同步、金标与门控 / 高|满足 AI 文档的误差、覆盖及误报门槛；蓝牙路径变化必须重校|
|F09 P1 同句版本切换，辅助听辨|老师与票友找对应句|老师对照关联两个版本 → 选句按 A/B → 各自前导、边界、实唱词联动|句关联、两份许可 / 中|缺句显式为空；重复句可指定第几次；独播且切换不沿用绝对秒数|
|F10 P1 拆解候选，减少备课|老师手工划线慢|已授权音频及可选词本 → 请求分析、对照、接受/改写 → 草稿时间轴|异步任务、ASR/分段 / 高|失败可继续手工编辑；未采纳项不能发布；与手工基线比较校订总时长|
|F11 P1 教学进展，安排下次课|老师难以查看练习覆盖|有权限班级及练习摘要 → 按句看完成/主动待练人数 → 备课列表|班级访问、告知、去重 / 中|仅本人负责班级可见；无数据与零完成分别提示|
|F12 P1 句旁知识卡，降低术语门槛|初学者不懂词义|点词/术语 → 看师审释义、出处和适用版本 → 回原位置|内容编辑、来源 / 低|卡片关闭后保留播放位置；未收录提示询问老师|
|F13 P2 音高节奏与个性训练，依赖可信观察|进阶者找薄弱处|多次获准分析 → 看局部轮廓、选采纳建议 → 生成待练清单|有效浊音、规则和样本 / 高|仅高可信可比区展示；拖腔、自由节奏按老师豁免；允许忽略建议|
|F14 P2 跨版本连续对齐，成本高|研究者比较速度与过门|成对修订及锚点 → 检查局部路径 → 波形联动|分段 DTW、人工确认 / 高|跳句处断链，编辑后映射失效，门槛见 AI 方案|
|F15 P2 有出处问答，需求待证|爱好者追问角色与历史|限定唱段提问 → 检索已审材料 → 回答附段落或拒答|知识授权、检索评测 / 高|引用可定位、无材料则退回已审卡，隔离未授权内容|
|F16 P2 视频与扩充入库，增加供给|机构整理影像|受权视频 → 提取音轨并保留视听时间偏移 → 审校后复用 F06|音画同步、转码与视频权利 / 高|含初始音画偏移的样本能对齐；无视频授权不得展示画面|

**范围裁剪。** 首期仅受邀老师上传音频，学员录音留在设备内存。P1 入点计算优先设备端；若拟送云端，需另行评估并取得针对该目的的授权。成果展示先用个人练习历史；公开作品墙、任意用户上传、自动判行当/流派和全曲艺术评分均无发布承诺。

**审查修订 · F10–F15 投入顺序。** F10 先计手工校订工时，沿用节时及成品质量双门槛。F11 先让老师用人工汇总实际调整下次课；F12 先记录同一术语反复引发的求助。F13–F15 留在研究清单，须有对应使用行为与独立评测再排期。
