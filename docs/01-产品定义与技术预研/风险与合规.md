# 风险归属与处置

暂按中国大陆成人封闭试点设计，发布负责人需以实际地区、合作协议、处理流程复核适用要求。下列控制是拟议产品设计。作品、表演、录音录像可能涉及不同权利主体，录音原件的持有人不必然有全部网络传播授权。[国家版权局《中华人民共和国著作权法》，2020 年修正，特别是第十、三十九、四十四条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)

|风险 / 触发点|责任人及实施控制|验证与处置|
|---|---|---|
|词曲、改编、伴奏、表演与录音录像权利链缺失|内容负责人逐项收集签约主体、权属凭证、署名、地域、到期、班级、是否允许切片/变速/播放/商业课/宣传/模型使用|任一必要用途不清即停该用途；投诉关联素材 ID，暂停新取流、核证、通知合作方并留处理结果|
|名家版本误署名，AI 改词或误判唱腔|教师签发带修订号的内容，保存原词与实唱差异；学生能反馈错句，审核员可撤课|关键错误撤回该修订，修正后发新课；避免把风格差异变成能力排名|
|录音及身份资料泄露|P0 原声只留页面内存，离页释放；账号记录限进度。展示用途、处理者联系渠道、查询删除入口。研究录音另签目的、期限、访问名单与退出方式|拒权仍能学；试点前网络抓包和删数演练；泄露时隔离权限、保全最小证据、依法评估通知|
|未成年人、声纹或跨境服务扩大处理范围|首期只招成人；不提取身份声纹。未满十四周岁处理、敏感信息、委托处理、跨境传输按实际流程另评估|上线前审数据流、供应商与地域；引入机构未成年人班或外部 API 前重审|
|恶意或超量媒体、未公开素材外流|按授权私有桶、隔离解码、时长/内存/并发限制、短效凭据、范围请求逐次鉴权|用无效媒体和跨班请求做防御测试；超时终止并回收临时对象|
|训练集与副本失控|权利台账区分展示、分析、训练、再分发；算法集逐样本记录同意及来源、版本、分割集|撤回后停用样本，列清派生特征、缓存、备份与模型影响，按协议处理并可核验；授权不明不进入训练|
|模型成本超支、外部服务故障|算法负责人以每分钟输入成本、重试、队列积压和缓存命中监测，按班预算封顶|达到额度返回手工编辑；超时不自动多次付费；供应商留存/训练条款不明禁传|
|合作老师退出或单一素材供应中断|项目负责人约定成品交付、修订权、退出、结算；给每个唱段设置替换关系|权利到期预警并撤课；以新授权版本发布，不能静默改历史记录|

《个人信息保护法》规定目的明确、最小必要、告知与删除等要求；生物识别信息及不满十四周岁未成年人的个人信息涉及特别保护。普通练习录音按可识别性和实际用途评估，不把设备麦克风授权等同于研究或训练同意。[工信部转载法律全文，检索于 2026-11-20](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)

**试点保存建议（待合同及负责人确认）。** 学员原声仅本次页面会话；课后摘要默认保存至班期结束后 30 天，允许提前删除；诊断日志建议 14 天、备份滚动 30 天，到期清除，恢复时重放删除清单。权利文件和必要审计记录根据合同及适用法定义务单独设期限；不得一并永久保存。未经授权不得对外发送试点报告中的个人明细。

**审查修订 · 权利链与训练集。** 内容负责人交一份逐项签核包：原件来源和哈希、词曲/改编/伴奏/表演/录制凭证、允许的班级及期限、切片和播放用途、老师与独立复核人、每段工时及报价。评测录音另列同意和删除期限。缺项阻断相应用途，先换委约样本再复核。
