# 试点研究、决策记录与未决项

下列为招募和实验设计，阈值均是拟议的继续投资条件。项目当前没有访谈、交易、金标、设备测量或留存实绩。

## 三个优先假设

|假设|方法与比较对象|通过信号 / 失败后的决定|
|---|---|---|
|H1 学员能独立完成一句并主动回来|招募同一剧种成人初学者约 12 人；交叉顺序用群视频与选句原型，观察寻句、听前导、录后对听；两周后回访。不同任务用难度相近的句避免记忆效应|建议 ≥9/12 无协助完成，且 ≥6/12 在随后七天不同日主动复练；分列老师催练。若只爱试听，先改听练入口或重新选人群|
|H2 教师能持续提供合法可校订的段落|邀 2 位老师记录整理台账、剪句、加提示、预览和返工人分钟；一人制作另一人复核，换角色；与其原备课法比，观察是否愿发给第二班|取得 3 段全链许可、2 人能独立完成各自任务、至少 1 人愿再布置；否则减曲库目标、改用委约录制或暂停对外试点|
|H3 入点提示可信且能改善下一次尝试|先做[离线盲评](声学与知识方案.md)，过门槛后在同一句做有无提示的交叉试验。用另一位老师盲判下一遍是否进入可接受窗口，同时记录误导/弃判|先过 F08 技术门槛，再观察有提示组进入窗口比例及误导样例；样本不足仅汇报方向。无增益则保留自听，将预算用于老师示范|

**访谈提纲。** 让学员展示最近一次真实练习，问“你在哪里倒回去，依据什么决定再来一遍？”让老师演示上周如何发作业、收纠错；追问“哪一步你不能交给机器？”让机构指出谁签权利、谁验收、谁付款。记下原话、观察、研究员解释三列，征得同意后匿名记录；拒录音可仅记笔记。后续付费测试分单课、订阅、教师工具三种真实可履约交付，不混算口头兴趣。

**指标字典。** 首练完成 = 同一次课项有录完并回听事件；仅试听另计可达性。次周主动复练 = 首练后第 1–7 天中至少另一天主动打开并再次完成，分母为观察窗完整的首练学员；另列第 8–14 天持续率。教师耗时 = 从拿到可用素材至获准发布的活跃工作分钟，等待授权的日历时间单列。事件为 open_course、listen_phrase、finish_record、review_take、flag_retry，记录匿名试点 ID、课项与时间；研究观察及事件采集先告知，退出者单列。小样本报告人数与分母，不能外推份额。
