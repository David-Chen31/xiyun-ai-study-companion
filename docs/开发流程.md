# 开发与验收流程

1. 先确认变更影响的是曲目制作、歌词跟唱、录音点评或本机模型。当前产品行为在[产品与验收](产品与验收.md)维护，运行步骤在[曲库与模型](曲库与模型.md)维护。
2. 曲目变更要用同一时间轴核对原唱、伴奏和逐句时间窗。审核过的逐字时间可用于字级回听，缺失时以句为单位。在发布素材前核对它的使用权限。
3. 声学变更要覆盖已知音高、持续偏差、孤立八度跳点、同句换音区、录音不覆盖和证据不足。点评模型使用可核实的数值和唱词，未知发音与情绪属于练法建议。
4. 前端变更应走查选曲、播放、拒麦、录音中断、文件导入、双轨对听、点评及较窄窗口。新功能不依赖旧版教师平台。
5. 交付前运行根目录测试并检查 Git 暂存区。模型权重、个人音频、密钥及本机推理产物放在忽略目录。
