# 戏韵 AI 学伴

戏韵 AI 学伴面向成人戏曲社团的课后练习。老师把有许可的示范录音整理成逐句作业，学员点一句唱词，就能从过门开始听、慢放、循环，再录下自己的演唱与示范交替回听。

**项目状态：产品定义与技术预研。** 当前仓库提供产品、架构、接口和协作文档。五天现场演示版是下一步的开发目标，仓库尚无可启动的软件或安装包。

## 演示版要交付什么

1. 在本机导入一段经独立复核的三句作业，保留示范署名和授权期限。
2. 学员在同一页面完成选句、试听、录音和对听。拒绝麦克风仍可听练，重新打开作业能回到待练句。
3. 操作员可以撤回作业。授权到期或撤回后，旧地址停止提供音频。

学员录音只在浏览器内存中回听。首轮使用教师标定的入点；自动入点反馈、拆解候选和连续跨版本对齐分别接受专门评测后，再决定是否开放。[功能清单与验收](docs/01-产品定义与技术预研/功能与验收.md) · [声学评测方案](docs/01-产品定义与技术预研/声学与知识方案.md)

## 三人如何开工

|负责人|首项交付|个人任务书|
|---|---|---|
|A · 业务后端与最终集成|提供能读取三句样例的作业地址，调用 C 的内部服务|[A 的五天计划](docs/team/A-队长与后端.md)|
|B · 前端与交互|用同一份样例完成可选句的练习页，再接 A 的地址|[B 的五天计划](docs/team/B-前端与交互.md)|
|C · AI 后端|用测试音启动独立的音频检查服务，返回时长和句界检查结果|[C 的五天计划](docs/team/C-AI后端.md)|

浏览器通过 A 获取课程和示范音频；A 在导入时调用 C，核对结果和授权后发布。已发布课程的播放独立于 C 的运行状态。三人第一天用相同样例核对成功与失败请求，第三天从正式入口跑通完整练习。[API 契约与样例](docs/team/API_CONTRACT.md) · [功能归属与每日集成计划](docs/team/TEAM_PLAN.md)
