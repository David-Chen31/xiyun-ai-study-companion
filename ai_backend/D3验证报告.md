## 本次完成

1. 回传并验证 request_id、revision_id、processor_version，提供调用侧 `validate_success` 函数，发现错编号/错修订/错版本时拒绝使用结果。服务不缓存旧修订结果。
2. 错误令牌返回 401；缺/坏字段与 JSON 返回 400；超限返回 413；坏或截断 WAV 返回 415；越界或重复句 ID 返回 422；内部意外异常返回 503。错误发生后后续正常请求可以成功。
3. HTTP 请求体设置默认 10 秒总读取期限，按剩余期限分块读取，避免慢客户端持续占用。所有结果关闭该次连接并带 `Cache-Control: no-store`，正常客户端可重新连接。A 的整个调用期限仍为 30 秒；10 秒只约束 C 读取请求体。
4. 未认证请求先回 401，再最多用 0.25 秒丢弃已在上传的数据，兼顾及时拒绝及 Windows 客户端读取错误 JSON。超大、提前拒绝请求仍可能遇到连接中断；调用方应处理传输异常。
5. multipart 改用标准库 MIME 解析并追加结构约束，拒绝重复字段、缺结束边界、错误/未知字段、嵌套与编码转换，保留 WAV 二进制原样。带引号的 boundary、大小写变体正常接收。
6. JSON 上限 256 KiB、嵌套上限 64 层，拒绝重复键、NaN/Infinity/溢出非有限数值、不成对 Unicode 代理字符；本机文件验证工具使用同样规则。空白 ID 不再视为有效 ID。
7. 启动时检查端口与 ASCII 可打印、无空白令牌；错误环境变量和非法配置返回可理解的启动错误，不直接输出堆栈。非法客户端令牌不会因非 ASCII 字符导致鉴权异常。
8. 新增一条命令验证停止/重启、同包重试、错误输入和指定临时目录无残留。服务无业务库，无课程发布或音频临时落盘。

## 复现命令

均在包含 `ai_backend` 的项目根目录运行：

```powershell
python -X utf8 -B -m unittest discover -s ai_backend/tests -t . -v
python -X utf8 -B -m ai_backend.check_d3
python -X utf8 -B -m ai_backend.check_basics --output ai_backend/reports/d3_basic_regression.json
```

`check_d3` 自动启动专用 C 子进程，使用空闲回环端口和随机内部令牌；测试期间会停止并在同端口重启自己启动的子进程，不会停止你已有的 8300 服务。测试结束终止子进程并清理其临时目录。不需要先开 C 服务，不需要配置令牌，无第三方依赖，也不访问外部网络。

默认报告是 `ai_backend/reports/d3_http_results.json`，可用 `--output` 改路径；只允许新建 JSON 报告或覆盖同类 D3 报告，不覆盖音频或 metadata。进程退出码 0 表示全部通过，1 表示有失败，2 为命令参数问题。

## A 可复用的结果核对

```python
import json
import os
from pathlib import Path
from ai_backend.replay import send_inspect, validate_success

samples = Path("ai_backend/samples")
metadata_bytes = (samples / "success_three.json").read_bytes()
metadata = json.loads(metadata_bytes)
status, result = send_inspect(
    "http://127.0.0.1:8300", os.environ["AI_BACKEND_TOKEN"],
    (samples / "demo_12s.wav").read_bytes(), metadata_bytes, timeout=30,
)
if status == 200:
    validate_success(result, metadata, expected_version="wav-inspect-1")
    # 接着由 A 复查当前草稿修订、许可和发布事务。
else:
    print(status, result)
```

这个函数只是调用侧检查工具，不会自动安装进 A 后端。调用方仍须在发布当时与自己的最新草稿再次比较 revision_id。
