# 基础素材验证：C 独立服务阶段

日期：2026-11-21（Asia/Shanghai）。环境：Windows / Python 3.13.5。处理器：`wav-inspect-1`。

## 本次任务口径

A 最新安排：C 先自行找几个基础素材，把后端功能跑通；接收参数和返回结构暂由 C 定义，之后再统一接口并对接 A 的业务后端。本次据此完成独立服务技术验证，教师课包尚未提供不再作为此阶段的阻塞项。

暂定接口沿用 `POST /internal/v1/inspect`，multipart 的 `audio` 和 `metadata`，Bearer 令牌。完整定义、字段、错误码、限额和调用示例见 [临时接口说明](临时接口说明.md)。
